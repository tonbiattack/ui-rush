# UI Rush デザイン方針

UI部品を実物で見て名前を当てるクイズなので、標本と罫線でできた紙のワークシートのような見た目にしています。角丸カード＋影の量産的なUIは避け、**画面で唯一明るい物体を「操作できるデモ」**にしています。

## トークン

| 用途 | 値 | 備考 |
| --- | --- | --- |
| 紙（背景） | `--color-paper` `#f1f2ed` | 少し緑を含む生成り |
| 面 | `--color-surface` `#fbfbf8` | デモ枠・入力欄 |
| 墨（文字・主ボタン） | `--color-ink` `#16191a` | ブランドカラーを兼ねる |
| 副次文字 | `--color-ink-soft` `#3b4243` / `--color-muted` `#616b6b` | 本文／補助 |
| 罫線 | `--color-rule` `#d5d8d0` / `--color-rule-strong` `#aeb3a8` | 区切り／操作枠 |
| 正解 | `--color-correct` `#0f6b55` | 状態表示のみ |
| 不正解 | `--color-wrong` `#a8261d` | 状態表示のみ |
| 時間切れ | `--color-timeout` `#7d5800` | 状態表示のみ |
| フォーカス | `--color-focus` `#ff4a00` | キーボード操作時のみ |

本文色はすべて紙・面に対して 4.5:1 以上（墨15.7:1、副次9.1:1、補助4.9:1、各状態色5.7〜6.3:1）。状態色は文字と記号（正解／不正解／時間切れ）を併記し、色だけに依存しません。

## 書体

- 表示・数字・英語ラベル: **Barlow Semi Condensed**（`--font-barlow`）。タイマーや問題番号は等幅数字（`.instrument`）で桁を揃える。
- 日本語: **Zen Kaku Gothic New**（`--font-zen-kaku`）。見出しは太字＋わずかな詰め、本文は `palt` 有効。

## レイアウト

- 幅は最大 4xl。設定は**仕様表**（左ラベル／右操作）で並べ、罫線だけで区切る。
- クイズは PC で2カラム（左に標本、右上に4択）、モバイルで縦積み。標本枠は四隅に目盛りを置き、デモを「標本」として扱う。
- 正誤と解説は回答後に標本の下へ現れ、そのとき画面の主役が解説に移る。
- 見出しの上に大文字ラベルを置かない。ラベルは日本語の短い名詞。

## モーション

- 自発的な演出は入れない。動くのは**残り時間バーの減算**と、状態が変わったことの表示だけ。
- 回答後、解説が見えない位置にあるときだけスクロール位置を移す（アニメーションなし）。
- `prefers-reduced-motion` では transition / animation を実質無効化。

## コピー

- キャッチコピーやスローガンを置かない（`AGENTS.md` の方針）。見出しは画面の役割をそのまま書く。
- 主ボタンは結果をそのまま言う（「クイズを始める」「次の問題へ」「結果を見る」）。
- 空状態は案内にする（「まだ記録がありません。1セッション終えると…」）。
- エラーは謝らず、次にできることを書く（「もう一度読み込む」）。
